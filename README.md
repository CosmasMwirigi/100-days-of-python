I'm learning Python in public on my way to becoming a data analyst. Every day I study, take handwritten notes, and turn them into documentation and working code in this repo.

## Why I'm doing this

The job market is tough. Learning in public keeps me consistent and shows exactly what I know, one day at a time.

## How to run the code

You need Python 3.10 or newer (`match` was added in 3.10).

```bash
cd day-01-conditionals
python 01_compare_if.py
```

## Repo structure

Each day has its own folder with:

- `README.md`: my notes for the day, written up properly
- `.py` files: runnable code examples, numbered in the order I learnt them
- `images/`: flowcharts and visual summaries
